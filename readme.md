Employee Management System

## Project Description

Employee Management System is a simple CLI-based application developed using Python and MySQL. It is used to manage employee information.

## Technologies Used

* Python
* MySQL
* SQL
* MySQL Connector
* Git
* GitHub

## Features

* Add Employee
* View Employees
* Update Employee Salary
* Delete Employee

## Database

Database Name: `employee_db`

Table Name: `employees`

Columns:

* id
* name
* salary

## Installation

Install the required package:

```bash
pip install mysql-connector-python
```

## How to Run

Run the following command:

```bash
python employee.py
```

## CRUD Operations

* Create → Add Employee
* Read → View Employees
* Update → Update Salary
* Delete → Delete Employee
